SpecGit

SpecGit 为 GitHub 与 GitLab 上的编码 Agent 提供统一的交付工作流。Issue 承载规格；原生 PR/MR 汇集选中的 Issue 与实现。SpecGit 读取代码托管平台的当前状态，让 Agent 可以修复失败，并区分待处理工作与已完成的交付。

下载最新版本 阅读 README 浏览 Wiki

安装

在目标仓库中打开你的编码 Agent，让它阅读并遵循 Agent 安装指南。指南会下载最新的已签名稳定 GitHub Release，校验签名与 SHA-256，安装共享 CLI，并初始化项目。

一个用户级可执行文件服务所有仓库与 worktree。最终用户安装不需要 Node.js、npm 或 Rust 编译器；仓库操作需要 Git 以及已认证的 gh 或 glab。GitHub Releases 是唯一分发渠道。

安装后，请对每个 clone 或 worktree 分别初始化，并查看离线能力清单：

specgit init --provider github --remote origin --check --json
specgit init --provider github --remote origin --dry-run --json
specgit init --provider github --remote origin --json
specgit setup --catalog --json

已安装？请使用 项目维护指南，不要重复首次安装流程。

宿主快速上手

SpecGit 的能力位于共享 CLI 与原生 Git guard 中，因此项目即使零宿主集成也能工作。用 --agent 选择宿主时只添加该宿主的指导与 Skill；hooks 与受管只读白名单是各自独立的显式选择。先用 --dry-run 预览，再执行不带该参数的命令应用。

Generic

指导入口写入 AGENTS.md，并使用规范 .agents/skills/specgit-native/SKILL.md。没有宿主回调；原生 Git guard 仍在 commit/push 时生效。

specgit setup --agent generic --dry-run --json
specgit setup --agent generic --json

回退：直接阅读指导与 Skill。详见：支持的宿主。

Claude Code

根 CLAUDE.md 入口、规范 .agents Skill，以及供宿主发现的 .claude/skills/specgit-native/SKILL.md 副本。上下文 hooks 与受管只读白名单均为可选项。

specgit setup --agent claude --dry-run --json
specgit setup --agent claude --json
specgit setup --agent claude --hook-purpose context --dry-run --json
specgit setup --agent claude --hook-purpose context --json
specgit setup --agent claude --readonly-permissions --dry-run --json
specgit setup --agent claude --readonly-permissions --json

白名单只减少提示，不是沙箱或授权边界。详见：支持的宿主。

Codex

获得规范 .agents Skill，指导入口写入 AGENTS.md；若已存在非空的 AGENTS.override.md，则写入该文件。上下文 hooks 写入 .codex/hooks.json。

specgit setup --agent codex --hook-purpose context --dry-run --json
specgit setup --agent codex --hook-purpose context --json

须在宿主 /hooks 中信任项目 .codex/ 层；在宿主实际导入前，注册状态为 written_not_verified。详见：支持的宿主。

OpenCode

官方构建获得根 AGENTS.md 入口与 .agents Skill；上下文 hooks 不支持。支持 Claude 兼容命令 hooks 的自定义 fork 可显式选择。

specgit setup --agent opencode --dry-run --json
specgit setup --agent opencode --json
# 仅自定义 fork：
specgit setup --agent opencode --opencode-claude-hooks --hook-purpose context --dry-run --json
specgit setup --agent opencode --opencode-claude-hooks --hook-purpose context --json

回退：直接重读指导与 Skill，并使用有界 watch/inbox；Git guard 独立生效。详见：支持的宿主。

支持矩阵

维护中的汇总见 支持的编码 Agent 与 支持的宿主；链接文档为准。

宿主 指导入口 Skill 发现 上下文 hooks 受管只读白名单 回退
generic AGENTS.md 宿主读取 .agents 时使用 .agents/skills/specgit-native/SKILL.md 无；不支持 不支持：宿主没有权限配置 直接阅读指导与 Skill
Claude Code CLAUDE.md 规范 .agents Skill，另有 .claude/skills/specgit-native/SKILL.md .claude/settings.json 的 SessionStart/PreToolUse 用 --readonly-permissions 写入 .claude/settings.json 的 permissions.allow 重读指导与 Skill
Codex AGENTS.md，或已存在的非空 AGENTS.override.md 规范 .agents Skill；Codex 从工作目录向上扫描到仓库根，并读取 ~/.agents/skills .codex/hooks.json；须在宿主 /hooks 中信任项目层 不支持：审批与沙箱仍属实验性 重读指导与 Skill
OpenCode（官方） AGENTS.md .agents Skill；宿主还读取项目 .opencode/ 与 .claude/ skills 无；不支持 不支持：默认放行，无可移植白名单 重读指导与 Skill；使用有界 watch/inbox
OpenCode 自定义 fork AGENTS.md 同官方 OpenCode .opencode/hooks.json，inputFormat: claude-code；须 --agent opencode --opencode-claude-hooks 并显式指定 hook 用途 不支持 同官方 OpenCode

guard 是原生 Git pre-commit/pre-push 检查，不是宿主回调。它对所有宿主生效，包括 generic：用 setup --hook-purpose guard 或 specgit guard --install 安装。上下文 hooks 是可选项，只负责提示和上下文，不承载业务规则。

下载

SpecGit 仅通过 GitHub Releases 分发。最新稳定版提供：

  • specgit-<version>-darwin-arm64.zip — macOS arm64
  • specgit-<version>-linux-x64-gnu.zip — Linux x64 glibc
  • specgit-<version>-win32-x64.zip — Windows x64
  • SHA256SUMS 与 SHA256SUMS.sigstore.json — 校验和清单及其 Sigstore 签名包

用 发布产物校验参考 校验签名与 SHA-256。签名只覆盖 SHA256SUMS，并由此覆盖 ZIP 字节；请另外交叉核对 tag commit 与原生构建工作流运行。
