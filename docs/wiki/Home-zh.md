# SpecGit Wiki

SpecGit 2 管理规格 Issue、原生 PR/MR 关联与状态观察。Agent 负责实现和修复，GitHub/GitLab 负责 CI、保护、评审和合并。确认目标合并与所有关联 Issue 关闭后，交付才算完成。

从[快速开始](Getting-Started-zh)进入；已有项目先看[升级指南](Upgrading-Existing-Projects-zh)。[团队工作流](Team-Workflow-zh)解释交付过程，[CLI 参考](CLI-Reference-zh)解释状态与写入边界。

这些页面的审阅源文件位于[docs/wiki](https://github.com/LeXwDeX/SpecGit/tree/main/docs/wiki)。
