# Core Concepts

One Issue represents one independently verifiable need with Why, Scope, Approach and Acceptance. A native PR/MR combines selected Issues and actual implementation. SpecGit reconciles native IDs and preserves closing references.

Pending, failed, unknown and completed states remain distinct. Preferences and previews grant no mutation authority. See the [native contract](https://github.com/LeXwDeX/SpecGit/blob/main/runtime/REFERENCE.md).
