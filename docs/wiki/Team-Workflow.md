# Team Workflow

Select complete Issues, preview and apply their association through `specgit issue`, then implement, verify, commit and push. Preview and create or adopt the request with `specgit pr`. Preserve every closing reference.

Use `specgit pr --status --json` and bounded `specgit watch` to inspect current evidence. The agent repairs failures and performs authorized native operations. Verify target merge and Issue closure. See [repository CI scope](https://github.com/LeXwDeX/SpecGit/blob/main/docs/ci-scope.md).
