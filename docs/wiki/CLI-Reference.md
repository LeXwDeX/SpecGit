# CLI Reference

Use `specgit --help` and offline `specgit --schema` to discover the installed native contract. Use `--json` for machine output and `--input-file` for explicit structured input. Exit zero reports a successful operation; it does not imply delivery completion.

The [native reference](https://github.com/LeXwDeX/SpecGit/blob/main/runtime/REFERENCE.md) documents commands, options, reports and diagnostics. v1 `finish`, `accept`, `bind` and `unbind` are retired.
